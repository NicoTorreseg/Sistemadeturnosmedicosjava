# Sistemadeturnosmedicosjava
Este proyecto fue realizado para la materia de proyectos informaticos de la carrera 
de la licenciatura en sistemas de informacion.
El proyecto fue realizado en JAVA como aplicacion de escritorio
Se utilizo bases de datos relacionales MySQL, Servidor de base de datos Apache de XAMMP

Objetivos del proyecto
Administrar y gestionar los turnos de los medicos de un el hospital Pineiro
Inclueye Altas bajas y modificaciones a la base da datos de Medicos, Pacientes, Turnos, Horarios.
Modelo MVC
Servicio con API REST
